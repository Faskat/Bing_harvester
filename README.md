# Bing Harvester

Маленькое приложение для Windows, которое каждый день само проходит Microsoft Rewards в Edge: ежедневный набор с викторинами, поиск для дневной серии и «Готово к получению».

*English: a tiny Windows app that completes the Microsoft Rewards daily set, keeps the search streak and claims points through Microsoft Edge. UI is in Russian.*

> [!WARNING]
> Автоматизация нарушает условия Microsoft Rewards. Аккаунт могут ограничить, а баллы — обнулить. Проект учебный, используйте на свой риск.

## Что умеет

- **Ежедневный набор** — 3 задания, включая викторины и опросы; после каждого проверяет, засчиталось ли, и при необходимости повторяет.
- **Поиск для серии** — 2 запроса в Bing. До лимита в 60 баллов намеренно не добивает: 20 однотипных запросов в день — самое заметное для Microsoft и может урезать бонус Bing Star.
- **Дополнительные задания** с баллами, если они есть на панели.
- **«Готово к получению»** — забирает накопленные баллы, пока не сгорели.
- **Каждый день по расписанию** через Планировщик Windows — окно для этого держать открытым не нужно.
- Паузы и набор текста как у человека, скорость настраивается.

## Установка

### Готовая сборка — проще всего

Нужны только **Windows 10/11** и **Microsoft Edge** (он уже есть в Windows). Node.js встроен.

1. Скачайте `BingHarvester-…-win-x64.zip` на странице **[Releases](https://github.com/Faskat/Bing_harvester/releases/latest)**.
2. Распакуйте архив **целиком** в любую папку, например `Документы\Bing Harvester`, и запустите **`Bing Harvester.exe`**.
3. **«Войти в Microsoft»** → войдите в открывшемся окне Edge. Окно закроется само.
4. Нажмите **«Собрать баллы»** или включите **«Каждый день»**.

Exe не подписан, поэтому Windows может показать «Система Windows защитила ваш компьютер» — нажмите **«Подробнее» → «Выполнить в любом случае»**. Не доверяете сборке — соберите её сами (ниже).

Вход и настройки хранятся в `%LOCALAPPDATA%\BingHarvester`, так что для обновления достаточно заменить папку. Расписание запоминает путь к exe: если перенесли папку, выключите и снова включите «Каждый день».

### Из исходников

Нужен ещё **[Node.js](https://nodejs.org/) 20+**.

1. `git clone` или **Code → Download ZIP**.
2. Запустите **`install.cmd`** — он поставит зависимости и создаст ярлык «Bing Harvester» на рабочем столе. Данные будут лежать в папке `data/` проекта.

Собрать exe самому: `npm run build` → `dist/Bing Harvester/` и zip рядом. Релизы собирает GitHub Actions при пуше тега `v*`.

## Безопасность

- Пароль вы вводите сами на сайте Microsoft в настоящем окне Edge — приложение его не видит и не хранит.
- Бот работает в отдельном профиле Edge (`data/profile`) — ваш обычный браузер не трогается.
- Всё личное лежит в `%LOCALAPPDATA%\BingHarvester` (у версии из исходников — в `data/`, она в `.gitignore`). **Никому не отправляйте эту папку** — там вход в ваш аккаунт.
- Окно — локальная страница на `127.0.0.1`: наружу ничего не открыто, запросы с других сайтов отклоняются.
- Одна зависимость — [`playwright-core`](https://www.npmjs.com/package/playwright-core) от Microsoft; npm-скрипты при установке отключены (`.npmrc`).

## Командная строка

Всё, что делает окно, доступно и без него:

```bash
node src/run.mjs                      # один запуск с настройками из окна
node src/run.mjs --login              # войти в аккаунт
node src/run.mjs --check              # проверить вход и баланс
node src/run.mjs --show --speed=slow  # с окном браузера, медленно
node src/app.mjs --no-window          # только сервер окна — для разработки
```

| Флаг | Что делает |
|---|---|
| `--show` / `--headless` | показать или спрятать браузер |
| `--speed=fast\|normal\|slow\|stealth` | множитель пауз: 0.6 / 1 / 3 / 6 |
| `--lang=ru\|uk\|en` | язык Bing и трендов для запросов |
| `--no-search` `--no-daily` `--no-more` `--no-quiz` `--no-clicks` `--no-claim` | отключить этап |

Коды выхода: `0` готово, `1` ошибка, `2` нужен вход, `3` остановлено, `4` уже идёт другой запуск.

## Как устроено

| Файл | Зачем |
|---|---|
| `launcher/BingHarvester.cs` | `Bing Harvester.exe` из сборки: запуск без консоли на встроенном Node.js |
| `scripts/build.mjs` | портативная сборка и zip для релиза |
| `Bing Harvester.vbs` | то же для версии из исходников |
| `src/app.mjs` | локальный сервер и окно Edge в режиме приложения |
| `src/run.mjs` | один запуск: сбор, вход, проверка |
| `src/bot.mjs` | этапы и итог |
| `src/dashboard.mjs` | чтение панели rewards.bing.com (2026: только DOM, API закрыт) |
| `src/quiz.mjs` | викторины и опросы |
| `src/search.mjs`, `src/queries.mjs` | поиск «как человек» и запросы из Google Trends |
| `src/scheduler.mjs` | задача `BingHarvester` в Планировщике |
| `data/` или `%LOCALAPPDATA%\BingHarvester` | профиль Edge, настройки, история, логи — не в git |

## Если что-то сломалось

Microsoft часто меняет панель Rewards. Откройте **Журнал → Папка логов** (`logs/ГГГГ-ММ-ДД.log` в папке данных) и приложите нужный кусок к issue — предварительно уберите из него имя и почту.

Не видно окно? Запустите `npm start` из папки проекта — ошибки будут в консоли.
